Audit Log — Compliance View

Every entry stores a SHA-256 hash of the previous entry, forming a tamper-evident chain — altering or deleting a past record breaks every hash after it. This view shows entries in write order for that reason; use Task Activity for searching/filtering/exporting the same data.
